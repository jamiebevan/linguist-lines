# Linguist Lines 

Linguist Lines is a personal Python project exploring the
intersection of linguistics and programming.

I'm building this project as I develop my Python skills,
with the long-term goal of exploring computational linguistics
and language analysis.

## Current Features

- Count the words in a sentence.
- Identify the longest word in a sentence.

## How to Run

Run the program using Python 3:

    python main.py

## What's Next?

As the project develops, I hope to explore:

- Word frequency analysis
- Vocabulary patterns
- Collocations
- Larger text datasets

The aim is to build my knowledge and improve the project
one step at a time.
